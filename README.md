# StayFree

Android app (Kotlin, Jetpack Compose, Room) that helps you quit or control an addiction.

Features: live streak timer, money and units saved, recovery milestones, craving log, urge SOS (4-7-8 breathing, 10-minute delay, tips),
insights (7-day chart, danger time, top triggers), slip tracking with best streak, multiple trackers.
Internet data: motivational quotes (zenquotes.io) and Wikipedia article summaries (cached offline).

## Build the APK (no Android Studio needed)
1. Create a new GitHub repository and upload everything in this folder (keep the .github folder).
2. Open the **Actions** tab, choose **Build APK**, press **Run workflow**.
3. When it finishes (about 5 minutes), open the run and download **StayFree-debug-apk**. Unzip it and install app-debug.apk.

## Build in Android Studio
Open the folder, let Gradle sync, press Run.

Not medical advice. If you drink heavily every day, do not stop suddenly without a doctor.
